⚙️ Compiler Architecture & Specifications

1
Lexer & Parser
Independent tokenizers and syntax parsers for Java, HTML (with Thymeleaf directives), and CSS stylesheets.
2
Abstract Syntax Tree (AST)
OOP hierarchy with line tracking, node polymorphic traversal using the Visitor Design Pattern.
3
Scoped Symbol Table
Hierarchical symbol tracking supporting classes, methods, endpoints, model attributes, templates, and iterations.
4
Semantic Analysis
Verifies controller endpoint bindings, returned template files, and referenced Thymeleaf model variables.
